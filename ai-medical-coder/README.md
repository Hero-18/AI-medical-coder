# AI Medical Coder

AI Medical Coder is a web-based application that helps identify suitable **ICD-11 medical codes** based on a patient's symptoms or disease information.

The goal of this project is to make medical coding easier by allowing users to enter symptoms or medical conditions and get relevant ICD-11 coding information.

## Features

- Enter symptoms or disease information
- Get relevant ICD-11 code suggestions
- Simple and user-friendly interface
- Fast search and response
- Responsive web interface
- Designed to make medical coding easier to understand

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
